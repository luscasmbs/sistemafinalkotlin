Desenvolvido como projeto de treinamento para a competição WorldSkills SENAI PE na modalidade de Desenvolvimento Mobile, este sistema demonstra domínio de estruturas de dados, algoritmos de busca e ordenação, e validação robusta de entradas.

fun adicionarContato(){
    println("=================================\n " +
            "ADICIONAR CONTATO\n" +
            "=================================\n\n" +
            "Digite o ID:")
    print("> ")

    var id = readLine()!!

    if (id.toIntOrNull() == null || id.toInt() <= 0){
        println("ERRO: ID inválido.")
        return

    } else if(usuarioscadastrados.any {
        it.id == id.toInt()
    }){
        println("ERRO: Já existe um contato com esse ID.")
        return
    }

    println("\nDigite o telefone:")
    print("> ")

    var telefone = readLine()!!

    telefone = telefone.filterNot {
        it == '(' || it == ')' ||
        it == '-' || it == ' '
    }

    usuarioscadastrados.add(
        usuarios(id.toInt(), nome, telefone)
    )

    println("Contato cadastrado com sucesso!")
}
Arquitetura e Lógica

Como o sistema funciona

Cada decisão arquitetural foi tomada com critério técnico, garantindo robustez, legibilidade e facilidade de manutenção.

● Armazenamento
A estrutura central é uma MutableList<usuarios> global. Simples e direta — sem overhead desnecessário para o escopo do sistema.
var usuarioscadastrados =
mutableListOf<usuarios>()
01
● Ordenação
Para listar, um MutableMap temporário é construído e toSortedMap() retorna cópia ordenada por ID sem modificar a lista original.
map.toSortedMap()
.forEach { println(it.value) }
02
● Busca
find{} percorre a MutableList com predicado lambda e retorna o primeiro match ou null, tratado com verificação explícita.
usuarioscadastrados
.find { it.id == id.toInt() }
03
● Parsing Seguro
toIntOrNull() impede que entradas não numéricas causem crash. Toda conversão é checada antes de prosseguir — padrão Kotlin idiomático.
if (op.toIntOrNull() != null) {
// seguro para processar
}
04
● Formatação
construirt() percorre os 11 dígitos com contador manual, inserindo (, ), espaço e - nas posições exatas.
if (contador == 0) t += '('
if (contador == 7) t += '-'
05
● UTF-8
System.setOut() com StandardCharsets.UTF_8 garante acentos no console — detalhe que demonstra atenção ao ambiente de execução real.
System.setOut(PrintStream(
System.`out`, true, "UTF-8"))
