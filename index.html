Sobre o Projeto

Este sistema foi criado para praticar conceitos fundamentais da programação utilizando Kotlin, com foco em lógica, estrutura de dados e organização.

Objetivo

Desenvolver um sistema de gerenciamento de contatos capaz de adicionar, buscar, atualizar, listar e remover usuários utilizando validações completas e uma interface organizada em terminal.

Aprendizados

Durante o desenvolvimento foram utilizados conceitos como funções, listas, mapas, data class, validações, loops, condicionais, tratamento de erros e padronização de dados.

Funcionalidades

O sistema possui diversas funcionalidades desenvolvidas para simular um sistema real.

Adicionar Contatos

Cadastro completo com validação de ID, nome e telefone.

Buscar Contatos

Busca rápida de contatos utilizando o ID informado pelo usuário.

Atualizar Dados

Alteração de nome, ID e telefone com verificações de duplicidade.

Remover Contatos

Exclusão segura com confirmação antes da remoção.

Validações

Tratamento de erros, entradas inválidas e prevenção de dados incorretos.

Ordenação

Listagem automática dos contatos organizados por ID.
